SLAY 2026 — подключение общего голосования

1. Создай проект на https://supabase.com/
2. Открой SQL Editor -> New query.
3. Скопируй содержимое supabase_setup.sql и нажми Run.
4. Открой Project Settings -> API и скопируй Project URL и публичный anon/publishable key.
5. В index.html замени:
   const SUPABASE_URL = 'ВСТАВЬ_SUPABASE_PROJECT_URL';
   const SUPABASE_ANON_KEY = 'ВСТАВЬ_SUPABASE_ANON_KEY';
   на свои значения.
6. Замени index.html в GitHub-репозитории подготовленным файлом. Все PNG-файлы оставь рядом с ним в корне репозитория.

ВАЖНО: используй только публичный anon/publishable key. Никогда не вставляй service_role или secret key в HTML.

После публикации проверь сайт в двух разных браузерах. Счётчики будут общими, а Realtime будет обновлять их у посетителей.

Ограничение повторного голоса основано на случайном ID в localStorage и уникальности (категория, voter_id) в базе. Это предотвращает обычное повторное нажатие, но не является надёжной проверкой личности: очистка данных сайта или другой браузер позволяют получить новый ID. Для строгого ограничения нужны авторизация и дополнительные меры против накрутки.
